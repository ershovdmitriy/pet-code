# Pet Code - платформа для проверки решений задач по программированию

**Pet Code** - это веб-приложение, позволяющее пользователям решать задачи по программированию на Java, отправлять код и получать автоматическую проверку на наборе тестов. Проект построен на Spring Boot, использует H2 для хранения данных и Docker для изолированного выполнения пользовательского кода с ограничением по времени и памяти.

Система поддерживает регистрацию и аутентификацию пользователей, просмотр списка задач, отправку решений и отображение детальных результатов выполнения (статус, время, пройденные тесты).

---

## Архитектура

Приложение построено по классической многослойной архитектуре Spring MVC и состоит из следующих ключевых компонентов:

1. **Контроллеры (Controller)** - обрабатывают HTTP-запросы, управляют навигацией и передают данные между представлениями и сервисами.
2. **Сервисы (Service)** - содержат бизнес-логику: управление пользователями, задачами, отправками решений.
3. **Репозитории (Repository)** - слой доступа к данным на основе Spring Data JPA.
4. **Сущности (Entity)** - JPA-модели, соответствующие таблицам базы данных.
5. **Исполнители кода (Execution)** - интеграция с Docker для компиляции и запуска Java-кода на тестовых наборах.
6. **Миграции (Flyway)** - управление схемой базы данных.
7. **Thymeleaf-шаблоны** - серверная генерация HTML-страниц для пользовательского интерфейса.
8. **Spring Security** - аутентификация и авторизация на основе логина/пароля (BCrypt-хэширование).

## Функциональные возможности

- ✅ Регистрация и вход пользователей.
- ✅ Просмотр списка доступных задач.
- ✅ Просмотр условия задачи и публичных примеров тестов.
- ✅ Отправка Java-кода в текстовом поле.
- ✅ Автоматическая проверка на всех тестах (публичных и скрытых).
- ✅ Детальный результат проверки:
  - Статус: *Accepted*, *Wrong Answer*, *Runtime Error*, *Time Limit Exceeded*, *Compilation Error*, *Internal Error*.
  - Количество пройденных тестов.
  - Время выполнения (суммарное по всем тестам).
- ✅ Хранение истории отправок для каждого пользователя.
- ✅ Просмотр страницы с результатом конкретной отправки.
- ✅ Изолированное выполнение кода в Docker-контейнере с лимитами времени и памяти.

## Запуск и сборка

### 1. Сборка Docker-образа для выполнения кода
```bash
cd docker/java-tester
docker build -t java-tester:latest .
```

### 2. Сборка и запуск Spring-приложения

```bash
mvn spring-boot:run
```
---

### Безопасность
- Код выполняется в изолированном Docker-контейнере с ограниченными ресурсами.
- Spring Security защищает эндпоинты, кроме публичных (/auth/register, /auth/login, статика, h2-console).

### Хранение данных
- Миграции Flyway автоматически создают схему при первом запуске.
- В БД хранятся:
  - `users` - логин и хэш пароля.
  - `tasks` - задачи.
  - `test_cases` - тесты, привязанные к задачам (с флагом `is_public`).
  - `submissions` - отправки решений пользователями.
